## 👨‍💻 About Me

I'm **Muhammad Rakib** — a full-stack engineer from **Dhaka, Bangladesh 🇧🇩** who builds production-shaped SaaS products and AI-powered systems end to end: from database schema and API design to React/Next.js front-ends, background workers, Docker deployments and the LLM/agent layer on top.

- 🏢 **Full-Stack Engineer @ [Combosoft Ltd](https://github.com/Combosoft-Ltd)** — building **[WMS360](https://wms360.co.uk)**, a multichannel warehouse-management platform for UK eCommerce sellers
- 🚀 Currently building **[ClinicPilot](https://github.com/muhammadrakib2299/clinicpilot)** — a multi-tenant control plane for healthcare AI agents (Claude tool-use · n8n · FHIR)
- 🤖 Deep into **agentic AI**: Claude tool-use copilots, MCP, multi-agent orchestration, RAG and explainable ML
- 🎓 B.Sc. in Computer Science & Engineering — **Daffodil International University**
- 📚 Every project ships with `PLAN.md` → `TODO.md` → `LESSONS.md` — I document what I build and what I learn
- 💼 Open to **full-stack / AI engineering roles**, freelance projects and interesting collaborations
- ⚡ Fun fact: I believe *clean code is a form of art* — and a good README is part of the product
